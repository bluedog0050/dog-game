# 🐾 狐狸犬電子寵物

手機網頁 3D 電子寵物（白色狐狸犬，low-poly 程式建模）。

## 玩法

| 數值 | 100→0 時間 | 回復方式 |
|---|---|---|
| 💗 快樂 | 30 秒 | 玩球 +40、摸摸 +8 |
| 🍖 飽食 | 60 秒 | 餵食 +50 |
| ⚡ 體力 | 90 秒 | 睡覺（每秒 +10，睡飽自動醒） |
| 🫧 清潔 | 120 秒 | 洗澡：用手指在牠身上搓 |

- 快樂歸零 3 秒 → **鬧脾氣**（背對你），摸 5 下原諒你
- 飽食或清潔歸零 10 秒 → **生病**（數值暫停），按「餵藥」
- 點頭 = 摸頭，點身體 = 翻滾
- 切到背景超過 10 秒或重新開啟 → 所有數值回到 50
- 點最上方的名字可以改名

## 開發

```bash
npm install
npm run dev      # 本機開發（手機連同網段可測試）
npm test         # 遊戲邏輯測試
npm run build
```

網址加上 `?debug` 可在 console 用 `__game` 操作狀態。

## 結構

```
src/
  data/        數值平衡（balance.ts）、台詞
  game/        純遊戲邏輯（可單獨測試）
  store/       Zustand 全域狀態
  scene/       3D：房間、狐狸犬、特效
  ui/          2D 介面
  audio/       Web Audio 合成音效
  hooks/       遊戲迴圈、背景偵測
```

調整手感只需要改 `src/data/balance.ts`。
